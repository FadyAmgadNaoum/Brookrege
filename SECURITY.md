# Security policy

## Reporting a vulnerability

Please report security problems privately — **not** in a public issue — to **security@brookrege.com** _(create this mailbox before launch)_
(or WhatsApp the number on the website and ask for the technical team). Include what you found, how to
reproduce it, and what an attacker could do with it.

We will confirm receipt within 3 working days, keep you updated, and credit you (if you wish) once it is fixed.
Please don't access or change other people's data beyond what's needed to show the problem, and don't run
denial-of-service or automated scanning against production. Good-faith research within these rules is welcome.
